Install in a minute

Trail isn't in the Chrome Web Store yet, so you load it yourself. It takes five steps.

  1. Download the zip and unzip it somewhere permanent.
  2. Open chrome://extensions in your browser.
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked and choose the unzipped trail folder.
  5. Pin Trail to your toolbar. Optionally add a free Groq API key in the popup for AI rewrites.

Questions

Is Trail free?

The extension is free. For AI-powered rewrites you add your own Groq API key, which Groq offers on a free tier.

Does it work without a key?

Yes. Without a key Trail wraps your draft in a clean role, task and constraints template locally. Add a key when you want a full AI rewrite.

Where does my text go?

Your API key is stored in your browser. When you click Optimize with a key set, your draft is sent to Groq to be rewritten. Nothing else leaves your machine.

Which sites does the inline button work on?

chatgpt.com and gemini.google.com. The popup works with any AI tool, since you copy the result out.
