Install Trail in 60 Seconds

Because Trail is 100% open-source and respects user sovereignty, you can load it directly into Chrome, Edge, Brave, or Arc.

  1. Download & Unzip: Grab trail-extension.zip and extract the folder to a permanent folder on your computer.
  2. Open Extensions: In Chrome, navigate to chrome://extensions (or edge://extensions in Microsoft Edge).
  3. Enable Developer Mode: Toggle the Developer mode switch in the top-right corner of the extensions page.
  4. Load Unpacked: Click the Load unpacked button and select the extracted trail directory.
  5. Pin & Optimize: Pin Trail to your browser toolbar! Open ChatGPT or Gemini to see the new button, or click the toolbar icon.

Frequently Asked Questions

Is Trail free to use?

Yes, 100% free and open-source under the MIT license. You can download, inspect the source code, modify it, and use it indefinitely.

Does Trail require an API key to work?

No! Trail works right out of the box with zero setup using its built-in Local Template Engine. If you want hyper-intelligent generative rewrites powered by Groq (LLaMA-3 / GPT-OSS), you can paste a free Groq key into the settings popup.

How is my privacy protected?

Trail operates on a strict zero-telemetry policy. Your prompts are never tracked, logged, or sent to any central server. When using Groq, calls are sent directly from your browser to Groq's API endpoint.

Which AI platforms are officially supported?

The inline one-click optimization button is currently integrated for chatgpt.com and gemini.google.com. The popup and live web demo work with every AI platform including Claude, Cursor, Copilot, and Perplexity.
